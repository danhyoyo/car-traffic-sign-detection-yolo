# Models

- `traffic_sign_classifier_lenet_v3.onnx`: bộ phân loại ảnh cắt 32×32 có sẵn.
- `pretrained/`: trọng số YOLO pretrained tải khi chạy notebook.
- `yolo11/`: mô hình `.pt`, `.onnx`, `sign_mapping.json` và cấu hình được xuất sau train.
